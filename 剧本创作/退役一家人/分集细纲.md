# 退役归来，这一家子不好惹

## 分集细纲

| 字段 | 内容 |
|------|------|
| 主线 | 兵王陈铁山退役，带着妻子“夜莺”林秀英、儿子陈野、女儿陈小满回到妻子老家云川县，在云川学院旁的槐树老街开“陈记早点”，全家立下家规“不惹事、不出手、不暴露”。全家四口个个武功盖世，却为了守住平凡日子一忍再忍，只敢“偷偷出手”。地痞刀疤强逼收保护费、富二代赵子豪校园霸凌、地产商赵金彪强拆老街，一层层把陈家逼到破戒；赵家背后的“阎先生”阎坤，正是十八年前被陈铁山夫妇端掉的跨境犯罪集团“黑蝎”的漏网头目。全家从隐忍到并肩，从防守到反击，配合警方扫除黑恶，守住老街。 |
| 关键配角逻辑 | 刀疤强：赵家打手，欺软怕硬，被陈家打服、又被林秀英救了老娘，反水作证。赵子豪：追陈小满不成转为霸凌，最后发现父亲要拿他顶罪，交出账本。赵金彪：要拆老街建商业城，陈记是最硬的钉子户，儿子挨打后公私一起报复，实为阎坤洗钱的白手套。阎坤：黑蝎首领，借赵家藏身洗钱，认出陈家后要“一个一个还”。苏晴：派出所女民警，起初怀疑陈家来路不明，实为省厅专案组暗线，与陈野有感情线。雷震：金彪武馆馆主，踢馆被陈铁山一招打服，转投陈家。王婶与街坊：起初嫌陈家窝囊，后来拿起锅铲一起守老街。 |
| 中段超级高潮 | 第 34–38 集：阎坤曝光陈家身份并纵火老街，趁乱绑走陈小满；全家四口兵分四路杀进水泥厂，第一次全员并肩血战；陈铁山为护儿女挡枪坠江，生死未卜。 |
| 后段核心兑现 | 陈铁山被渔民救起、秘密养伤，全家假办灵堂引蛇出洞；刀疤强、赵子豪先后反水，账本原件到手，赵金彪落网；阎坤劫持毕业典礼，陈铁山归来，全家四路破局，天台终战擒获阎坤，黑蝎覆灭；原部队首长到老街授勋，街坊才知道“窝囊老陈”一家是谁；老街保住，陈记重开，新家规：“不惹事，但事来了，不怕事。” |

## 第一阶段：老街地痞（第 1–12 集）

### <span style="color:#1E5AA8">**第 1 集 退役第一天**</span>

- 陈铁山脱下军装回到云川，妻儿在车站接他，全家在新租的铺面里宣读家规：不惹事、不出手、不暴露。陈记早点开张当天，刀疤强带人收三千块“开业费”，掀翻蒸笼，滚烫的豆浆泼向陈小满，林秀英用托盘一挡，一滴没洒，随即低头赔笑掏钱。陈野攥拳上前，被陈铁山死死按住。刀疤强临走踩碎全家福，丢下一句“明天起每天两百”。
  - <span style="color:#888888">*关键台词：林秀英：“咱家规矩第一条——谁也不许动手。”*</span>

### <span style="color:#1E5AA8">**第 2 集 拿命换的太平**</span>

- 当夜收拾残局，陈野不服：“咱家随便一个人，都能把他们打进医院。”陈铁山只说这份太平是拿命换来的，不能为一口气砸了。次日兄妹去云川学院报到，富二代赵子豪开跑车堵在校门口，看上陈小满，当众撒钱让她捡。陈小满绕开走，赵子豪脸色一沉。
  - <span style="color:#888888">*关键台词：赵子豪：“在云川，我看上的东西，还没有拿不到的。”*</span>

### <span style="color:#1E5AA8">**第 3 集 器材室**</span>

- 赵子豪的跟班把陈小满骗进体育器材室，七个男生关门围上来。门外只听见一阵闷响，门再打开时，七个人全躺在地上，陈小满拍拍校服，说是他们自己摔的。跟班们不敢承认被女生打了，一口咬定是她哥干的。
  - <span style="color:#888888">*关键台词：陈小满：“家规说不许出手，可没说不许别人自己摔。”*</span>

### <span style="color:#1E5AA8">**第 4 集 只躲不打**</span>

- 赵子豪带体育系十几个人在篮球场堵住陈野，逼他下跪。陈野挨了一拳不还手，接着十几根球棒砸下来，他只躲，五分钟里没人碰到他的衣角，全场学生举着手机拍。来学校做反诈宣讲的民警苏晴喝止了这场围殴，盯着陈野的步法皱起了眉。赵子豪颜面尽失，拨通了父亲的电话。
  - <span style="color:#888888">*关键台词：陈野：“我答应我爸不还手，可没答应他不躲。”*</span>

### <span style="color:#1E5AA8">**第 5 集 老板娘倒垃圾**</span>

- 半夜，刀疤强的手下往陈记门口泼红漆，写了个大大的“拆”字。林秀英拎着垃圾袋出门，在暗巷里用一根擀面杖把五个人全部打晕，挂在了电线杆上。第二天老街炸了锅，谁也想不到是谁干的。刀疤强却在现场捡到一根擀面杖，上面刻着“陈记”。
  - <span style="color:#888888">*关键台词：林秀英：“倒个垃圾，顺手的事。”*</span>

### <span style="color:#1E5AA8">**第 6 集 一记耳光**</span>

- 刀疤强拿着擀面杖上门问罪，陈铁山主动认下，说是自家丢的，当着全街人的面挨了一记耳光，赔着笑脸道歉，街坊们骂他窝囊。地产商赵金彪随后登场，扔下拆迁协议：一平米八百，三天搬走。王婶劝陈家签字走人，别连累整条街。
  - <span style="color:#888888">*关键台词：赵金彪：“三天后挖掘机进场，人在不在里头，我不管。”*</span>

### <span style="color:#1E5AA8">**第 7 集 兄妹夜探**</span>

- 兄妹咽不下父亲挨的那一巴掌，瞒着爸妈夜探金彪地产。陈小满破解门禁，陈野翻墙，两人查出拆迁公示是伪造的，还听见赵金彪恭恭敬敬地给一位“阎先生”打电话。三十个保安围上来，兄妹背靠背杀出一条路。两人回到家，客厅的灯亮着，爸妈坐在沙发上等着他们。
  - <span style="color:#888888">*关键台词：陈野：“小满，左边十五个归你。”陈小满：“哥，你那边十五个打得完吗？”*</span>

### <span style="color:#1E5AA8">**第 8 集 家庭会议**</span>

- 林秀英揭穿兄妹，原来她一整晚都蹲在对面楼顶替他们掩护。家庭会议上，陈铁山坚持守家规，孩子们红了眼，说爸挨的那一巴掌他们咽不下，林秀英嘴上训孩子，心里站在孩子这边。第二天苏晴来早点铺调查金彪地产夜闯案，握手时摸到了陈铁山虎口的老茧。
  - <span style="color:#888888">*关键台词：苏晴：“陈叔，你这手上的茧，不像是揉面揉出来的。”*</span>

### <span style="color:#1E5AA8">**第 9 集 挖掘机进场**</span>

- 三天期限到，挖掘机开进老街，王婶的馄饨摊第一个被推翻，王婶摔断了腿。刀疤强带二十多个人围住陈记，把陈铁山按在地上逼他按手印。陈小满在巷口被赵子豪的人拦住。刀疤强一脚踹向护着丈夫的林秀英——
  - <span style="color:#888888">*关键台词：刀疤强：“按！今天这手印，你不按也得按！”*</span>

### <span style="color:#1E5AA8">**第 10 集 今天这规矩，我破了**</span>

- 林秀英单手接住刀疤强踹来的脚。陈铁山站起身，摘下围裙。全家同时破戒：陈铁山一拳打碎挖掘机的驾驶室玻璃，把司机拎了出来；林秀英一根擀面杖扫倒二十人；陈野从屋顶跃下；陈小满在巷口放倒了赵子豪的人。刀疤强跪地求饶。警笛响起，赵金彪带着警察赶到，指着陈家喊“暴力抗法，全抓走”。（付费卡点）
  - <span style="color:#888888">*关键台词：陈铁山：“老婆，今天这规矩——我破了。”*</span>

### <span style="color:#1E5AA8">**第 11 集 权限不足**</span>

- 陈家四口被分开审讯，四个人口供一模一样，滴水不漏。陈小满调出她早就备份好的监控：挖掘机违规进场，刀疤强先动手。拄着拐的王婶带着街坊赶来作证，四人被当场释放。苏晴不死心，在系统里查陈铁山的档案。
  - <span style="color:#888888">*关键台词：（电脑屏幕）“该人员档案涉密，权限不足。”*</span>

### <span style="color:#1E5AA8">**第 12 集 有人来踢铺**</span>

- 陈记重新开张，街坊们排起长队，王婶第一个来买油条，算是给陈家赔不是。赵金彪痛骂刀疤强废物，转头请来金彪武馆馆主雷震。一个光头壮汉在早点铺坐下，一掌拍碎了桌子。
  - <span style="color:#888888">*关键台词：雷震：“听说你们家——很能打？”*</span>

## 第二阶段：武馆与赵家（第 13–33 集）

### <span style="color:#1E5AA8">**第 13 集 战书**</span>

- 雷震当面羞辱陈铁山，说当兵的全是软蛋，陈铁山笑着不接招。雷震一拳砸向灶台，林秀英手里的面团轻轻一托，把他的拳头卸到一边，面团完好无损。雷震下了战书：三天后到武馆比四场，陈家输了就滚出云川，不来就天天上门砸。陈野抢先接下了战书。
  - <span style="color:#888888">*关键台词：陈野：“四场？巧了，我家正好四口人。”*</span>

### <span style="color:#1E5AA8">**第 14 集 三秒**</span>

- 金彪武馆里坐满了人，赵家父子在场观战。第一场，陈小满对女子散打冠军，全场哄笑，觉得她是来送人头的。三秒后冠军倒地，陈小满借力一推，对手飞出了擂台。赵子豪的笑僵在脸上，他悄悄往陈野的水杯里下了药。
  - <span style="color:#888888">*关键台词：陈小满：“太极讲究四两拨千斤，你……有点重。”*</span>

### <span style="color:#1E5AA8">**第 15 集 带药上场**</span>

- 第二场，陈野对地下拳王马彪，刚上台就觉得头晕腿软，被打得满脸是血。陈小满在台下看出不对，冲哥哥做了个手势，陈野咬破舌尖保持清醒，用腿法反杀，一记鞭腿把马彪踢昏。下台后他直接栽倒在妹妹怀里。
  - <span style="color:#888888">*关键台词：陈野：“爸说过，倒下之前，先把对面放倒。”*</span>

### <span style="color:#1E5AA8">**第 16 集 一招**</span>

- 第三场，林秀英对副馆主，赵金彪嘲笑“老娘们儿上来凑数”，林秀英一双筷子钉穿了对手的袖口，把人钉在柱子上。最后一场，雷震对陈铁山，只一招就跪倒在地。雷震认出了这一拳的路数，满脸震惊。武馆角落里，一个戴墨镜的男人收起了手机。
  - <span style="color:#888888">*关键台词：雷震：“这是……利刃大队的军体拳？你到底是谁？！”*</span>

### <span style="color:#1E5AA8">**第 17 集 我要拜师**</span>

- 雷震当众和赵金彪翻脸，天天堵在陈记门口要拜陈铁山为师，被林秀英拿去当免费劳力揉面。陈小满把赵子豪下药的监控交给学校，赵金彪捐了一栋楼，把事压了下去。苏晴来警告陈野别再惹事，两人一起追了个小偷，在巷子里撞了个满怀。
  - <span style="color:#888888">*关键台词：苏晴：“你爸到底是干什么的？”陈野：“卖油条的。”*</span>

### <span style="color:#1E5AA8">**第 18 集 毒豆浆**</span>

- 二十个学生喝了陈记的豆浆后集体呕吐，被送进医院。陈记被查封，网上骂声一片，街坊们也开始犹豫。陈铁山作为负责人被带走调查，林秀英站在封条前，脸上没有任何表情。
  - <span style="color:#888888">*关键台词：林秀英：“小满，查。这回妈亲自来。”*</span>

### <span style="color:#1E5AA8">**第 19 集 夜莺出巢**</span>

- 林秀英易容成护工混进病房，几句闲聊就套出真相：这些学生每人收了赵子豪五百块，专门来装病。陈小满恢复了被删的监控，锁定往豆浆桶里下药的是赵家的保安。那名保安得到风声，连夜赶往火车站。
  - <span style="color:#888888">*关键台词：林秀英（护工装扮）：“小伙子，装吐也挺累的吧？”*</span>

### <span style="color:#1E5AA8">**第 20 集 火车站**</span>

- 林秀英和陈野在火车站截人，保安跳上即将开动的列车，陈野在车顶狂奔追上，把人按住。陈小满开着直播放出保安的认罪视频，陈记沉冤得雪，陈铁山被释放，赵子豪被学校记大过。赵金彪在办公室里砸了杯子，拨通一个号码。
  - <span style="color:#888888">*关键台词：赵金彪：“阎先生，那家人……我搞不定了。”*</span>

### <span style="color:#1E5AA8">**第 21 集 阎先生**</span>

- 赵家别墅里，阎坤反复看着武馆那段视频，停在陈铁山出拳的那一帧。陈家这边正给陈铁山过生日，三十秒的闪回里，兄妹俩小时候跟着爸妈在深山里扎马步。生日宴散后，陈小满放学路上，身后跟了一辆黑色面包车。
  - <span style="color:#888888">*关键台词：阎坤：“这一拳，我十八年前见过一次。”*</span>

### <span style="color:#1E5AA8">**第 22 集 纹身**</span>

- 陈小满察觉被人跟踪，反手把人引进了死胡同。五个职业打手围上来，出手招招致命，和老街的地痞完全不是一个级别。她以柔克刚放倒了所有人，在其中一人的手腕上看到一只黑蝎纹身。她拍下照片发给妈妈，林秀英手里的碗摔得粉碎。
  - <span style="color:#888888">*关键台词：陈小满：“妈，黑蝎……是什么？”*</span>

### <span style="color:#1E5AA8">**第 23 集 十八年前**</span>

- 家庭会议上，爸妈第一次说出往事：十八年前，林秀英卧底黑蝎，陈铁山带队把它端掉，只有首领逃了出去，那人发誓要灭他们满门，所以全家这些年才一直隐姓埋名。走还是留，四个人一起投票。兄妹俩说，咱们一走，老街的人怎么办。全票留下。
  - <span style="color:#888888">*关键台词：陈铁山：“好。从明天起，全家恢复训练。”*</span>

### <span style="color:#1E5AA8">**第 24 集 天台特训**</span>

- 每天凌晨，全家在天台对练，林秀英一个人打三个，爸爸和孩子三人联手也近不了她的身，陈铁山揉着腰承认全家最能打的是老婆。苏晴夜里巡逻撞见这一幕，惊呆了。赵金彪雇来外地一家保安公司，一百个人扬言明早清空老街。
  - <span style="color:#888888">*关键台词：陈铁山：“我怕老婆？我那是打不过。”*</span>

### <span style="color:#1E5AA8">**第 25 集 百人围街**</span>

- 天一亮，一百个保安封住老街的四个巷口，刀疤强混在人群里，脸色犹豫。陈家四口一人守一个巷口。陈铁山搬出一张小板凳坐在路中间，慢慢喝完了一碗豆浆。
  - <span style="color:#888888">*关键台词：陈铁山：“一人一条巷子，谁先打完，谁回来炸油条。”*</span>

### <span style="color:#1E5AA8">**第 26 集 一人一巷**</span>

- 四个巷口同时开打，四套招式各有看头。雷震带着武馆弟子赶来助阵，街坊们拿着锅铲擀面杖冲了出来。王婶看见林秀英的身法，当场落泪，认出这是老林家的拳。苏晴带着上级赶到，以拆迁程序违法为由叫停了强拆。
  - <span style="color:#888888">*关键台词：王婶：“这是老林家的拳！秀英，你是林老爷子的闺女？”*</span>

### <span style="color:#1E5AA8">**第 27 集 刀疤强的老娘**</span>

- 赵金彪要刀疤强出来顶罪，还扣下了他母亲的救命钱。林秀英得知后，默默替刀疤强的母亲交了医药费。刀疤强在病房外看见她的背影，一个大男人哭成了泪人。夜里，他跪在了陈记门口。
  - <span style="color:#888888">*关键台词：刀疤强：“嫂子，我有件事，必须跟你们说。”*</span>

### <span style="color:#1E5AA8">**第 28 集 黑账本**</span>

- 刀疤强说出秘密：赵金彪有一本黑账，锁在别墅的保险柜里。刀疤强刚出陈记就被赵家的人截住，要打断他的腿，陈野及时赶到，一脚踢飞了钢管。赵金彪那边宣布，下周在别墅为“阎先生”办寿宴。
  - <span style="color:#888888">*关键台词：林秀英：“寿宴？正好，妈去给他拜个寿。”*</span>

### <span style="color:#1E5AA8">**第 29 集 寿宴**</span>

- 寿宴当晚，林秀英扮成服务员，陈小满扮成钢琴手，陈野在外围接应，陈铁山开车守在路口。陈小满借弹琴掩护潜进书房开保险柜，林秀英端着酒盘走到主桌前，看清了寿星的脸，托盘差点脱手。
  - <span style="color:#888888">*关键台词：林秀英（OS）：“阎坤……十八年了，你还活着。”*</span>

### <span style="color:#1E5AA8">**第 30 集 你我见过**</span>

- 陈小满拷下账本，保险柜的警报却响了。阎坤盯着林秀英端酒的手腕，举起了杯子。林秀英面不改色地倒酒，桌下的筷子已经扣在了指间。
  - <span style="color:#888888">*关键台词：阎坤：“这位服务员，我们是不是在哪儿见过？”*</span>

### <span style="color:#1E5AA8">**第 31 集 夜莺暴露**</span>

- 林秀英掀翻酒桌，带着女儿往外冲，阎坤手下的职业杀手一路追杀，她用托盘、筷子、桌布在别墅里打出一条路。陈野撞开后窗接应，三人跳上陈铁山的车冲了出去。阎坤看着监控回放，笑了。
  - <span style="color:#888888">*关键台词：阎坤：“夜莺在这儿……那铁山，也一定在。”*</span>

### <span style="color:#1E5AA8">**第 32 集 U 盘被抢**</span>

- 陈野把账本 U 盘交给苏晴，苏晴开车回局里的路上被一辆渣土车撞翻，U 盘被抢走，她重伤住院。陈野守在病床边，苏晴昏迷前抓着他的手，叫他别冲动。陈野走出医院，眼神变了。
  - <span style="color:#888888">*关键台词：陈野：“爸，这回你别拦我。”*</span>

### <span style="color:#1E5AA8">**第 33 集 好久不见**</span>

- 陈野一个人闯进赵家，打穿两层保镖，掐住了赵子豪的脖子，却发现这是个圈套，黑蝎的杀手从四面围了上来。危急关头陈铁山破门而入，十八年后，第一次和阎坤正面相对。阎坤抬手让手下退开。
  - <span style="color:#888888">*关键台词：阎坤：“铁山，好久不见。今天不打——我要你全家，一个一个还。”*</span>

## 第三阶段：中段超级高潮（第 34–38 集）

### <span style="color:#1E5AA8">**第 34 集 全网曝光**</span>

- 阎坤把武馆视频和陈家的住址一起挂到了网上，陈家被网暴，恐吓电话打爆了老街。阎坤命令赵金彪今晚动手，一把火烧了老街。陈铁山连夜疏散街坊，陈小满留在学校宿舍远程删帖。
  - <span style="color:#888888">*关键台词：阎坤：“烧干净点。让他们看着家没了。”*</span>

### <span style="color:#1E5AA8">**第 35 集 老街大火**</span>

- 深夜老街起火，陈铁山和陈野踹门救人，林秀英冲进火场，把被困的王婶背了出来。与此同时，宿舍里的陈小满被六个杀手偷袭，她放倒了四个，最后被迷药捂倒，拖上了车。陈铁山的手机收到一段视频。
  - <span style="color:#888888">*关键台词：（视频里阎坤）“城西水泥厂，一个人来。”*</span>

### <span style="color:#1E5AA8">**第 36 集 兵分四路**</span>

- 陈铁山按要求一个人走正门，林秀英从后山的排水渠潜进去，陈野爬上了塔吊。被绑着的陈小满醒过来，用藏在发夹里的刀片割断了绳子，悄悄放倒了看守，又用看守的手机黑进了厂区监控。一家四口在耳机里重新接上了线。
  - <span style="color:#888888">*关键台词：陈小满：“爸妈，哥，我在三号仓。监控已经归我了。”*</span>

### <span style="color:#1E5AA8">**第 37 集 全家并肩**</span>

- 全剧最大的一场打戏：四个人对三十个黑蝎杀手。林秀英对上阎坤的头号杀手黑狼，打了个旗鼓相当；陈野在塔吊上一人缠住十个；陈小满引着敌人钻进陷阱；陈铁山一路打穿正面。黑狼被林秀英废掉，阎坤拎着枪逃向江边。
  - <span style="color:#888888">*关键台词：林秀英：“十八年没动真格的，手生了——你运气不错。”*</span>

### <span style="color:#1E5AA8">**第 38 集 坠江**</span>

- 江边，阎坤把枪口对准追上来的兄妹，陈铁山扑过去，替孩子挡下了子弹，抱着阎坤一起坠进江里。最后只有阎坤被手下拖上了岸。林秀英站在江边，江面上漂着一顶旧军帽。
  - <span style="color:#888888">*关键台词：陈小满：“爸——！”*</span>

## 第四阶段：反击（第 39–49 集）

### <span style="color:#1E5AA8">**第 39 集 他从不失约**</span>

- 全家沿江搜了三天，警方初步认定陈铁山已经遇难。林秀英一滴眼泪都没掉，照常开铺子。赵金彪趁机再提强拆，街坊们自发围在陈记门口守着。傍晚，一个跛脚的老兵走进店里。
  - <span style="color:#888888">*关键台词：老兵：“嫂子，我是猴子。连长让我来的。”*</span>

### <span style="color:#1E5AA8">**第 40 集 假灵堂**</span>

- 陈铁山的老部下侯勇带来消息：陈铁山被下游的渔民救起，现在秘密躺在部队医院，伤重还没醒。为了引阎坤出来，全家决定假装办丧事，在铺子里搭起了灵堂。消息放出去当晚，阎坤说要亲自来吊唁。
  - <span style="color:#888888">*关键台词：林秀英：“哭，要哭得真。仇，要记得狠。”*</span>

### <span style="color:#1E5AA8">**第 41 集 吊唁**</span>

- 阎坤带人闯进灵堂上香，当着林秀英的面嘲讽陈铁山。陈野差点冲上去，被林秀英一个眼神按住。陈小满借着递香，把一枚追踪器贴在了阎坤的袖口。定位显示，阎坤离开后直奔赵家的码头仓库。
  - <span style="color:#888888">*关键台词：阎坤：“嫂子节哀。下一炷香，我给你们娘仨一起上。”*</span>

### <span style="color:#1E5AA8">**第 42 集 码头仓库**</span>

- 陈野和侯勇夜探码头仓库，发现金彪地产其实是黑蝎走私洗钱的壳子，拍下了证据。两人被发现后陷入重围，危急时刻，警灯照亮了码头，带队的是刚出院的苏晴。
  - <span style="color:#888888">*关键台词：苏晴：“陈野，我说过别冲动——不过这回，干得漂亮。”*</span>

### <span style="color:#1E5AA8">**第 43 集 专案组**</span>

- 苏晴亮出真实身份：她是省厅专案组安在云川的暗线，盯赵家已经一年了，现在只差账本原件和阎坤露面。两家人坐下来商量联手收网，陈野和苏晴的感情在这一集挑明。就在这时，刀疤强失踪了。
  - <span style="color:#888888">*关键台词：苏晴：“我接近你家，一开始是为了查你们。后来……是为了你。”*</span>

### <span style="color:#1E5AA8">**第 44 集 采石场**</span>

- 赵金彪把刀疤强绑到采石场，准备灭口。林秀英带着雷震赶去救人，一根擀面杖对上一排钢管。刀疤强得救后答应出庭作证，还说出了另一个秘密。
  - <span style="color:#888888">*关键台词：刀疤强：“账本原件……在赵子豪手里。”*</span>

### <span style="color:#1E5AA8">**第 45 集 约会**</span>

- 陈小满主动答应赵子豪的约会，想套出账本的下落。相处中她发现，这个嚣张的富二代其实一直活在父亲的阴影里。她把赵金彪准备拿儿子顶罪的录音放给赵子豪听。
  - <span style="color:#888888">*关键台词：赵子豪：“我爸……要我替他坐牢？”*</span>

### <span style="color:#1E5AA8">**第 46 集 父子反目**</span>

- 赵子豪偷出账本原件，交给了陈小满。赵金彪发现后，竟然派人追杀亲生儿子。陈野在高架桥下救下赵子豪，赵子豪红着眼睛，向兄妹俩低头道歉。
  - <span style="color:#888888">*关键台词：赵子豪：“陈野……以前那些事，对不起。”*</span>

### <span style="color:#1E5AA8">**第 47 集 赵金彪落网**</span>

- 专案组在商会年会上收网，赵金彪劫持王婶当人质，拿枪顶着她的头。林秀英隔着十米甩出一根筷子，打落了他手里的枪，赵金彪被当场按倒。审讯室里，他却冷笑起来。
  - <span style="color:#888888">*关键台词：赵金彪：“抓了我有什么用？阎先生今晚，要你们全家陪葬。”*</span>

### <span style="color:#1E5AA8">**第 48 集 夜袭陈记**</span>

- 当晚，阎坤派出所有剩下的杀手夜袭陈记。陈家、武馆弟子和街坊们早就布好了口袋阵。可杀手人数远超预料，林秀英和兄妹被逼到灶台边，黑狼的副手举刀劈了下来。
  - <span style="color:#888888">*关键台词：陈野：“妈，小满，往我身后站！”*</span>

### <span style="color:#1E5AA8">**第 49 集 铁山归来**</span>

- 一只缠着绷带的大手握住了刀刃，陈铁山回来了，一拳把副手轰出了门。全家抱成一团，林秀英这才第一次落泪，捶着丈夫骂他吓死人。阎坤得知陈铁山还活着，启动了最后的计划。
  - <span style="color:#888888">*关键台词：陈铁山：“老婆，我说过，我从不失约。”*</span>

## 第五阶段：终局（第 50–55 集）

### <span style="color:#1E5AA8">**第 50 集 毕业典礼**</span>

- 云川学院毕业典礼当天，陈野穿着学士服上台，全家坐在台下。阎坤的人封死了礼堂大门，在座位底下安了炸弹，上千名师生成了人质。阎坤打来电话，只要陈铁山一个人上天台。
  - <span style="color:#888888">*关键台词：阎坤：“十八年的账，今天在天台上算清。”*</span>

### <span style="color:#1E5AA8">**第 51 集 四路破局**</span>

- 陈小满钻进礼堂的配电室，一边黑进引爆器一边动手拆弹；陈野和苏晴带着师生分批撤离；林秀英爬进吊顶，一根接一根用筷子放倒混在人群里的枪手；陈铁山一步一步走上天台。倒计时只剩最后十秒，陈小满剪下了最后一根线。
  - <span style="color:#888888">*关键台词：陈小满：“红线还是蓝线？——都不剪，我直接黑了它。”*</span>

### <span style="color:#1E5AA8">**第 52 集 天台终战**</span>

- 天台上，陈铁山对阎坤，两个人都受过伤，招招是十八年前没打完的死斗。阎坤掏出最后一把刀，陈铁山空手夺刃，一拳把他打倒在天台边上，没有补上那一下，把人交给了赶来的警察。
  - <span style="color:#888888">*关键台词：陈铁山：“我退役了。你，交给法律。”*</span>

### <span style="color:#1E5AA8">**第 53 集 黑蝎覆灭**</span>

- 专案组宣布，黑蝎在境内外的网络被一锅端。赵子豪出庭指证父亲，刀疤强因立功减刑，雷震的武馆改成了少年武术班。兄妹俩回到校园，同学们看他们的眼神全变了。
  - <span style="color:#888888">*关键台词：刀疤强：“嫂子，我出来那天，能来你家铺子揉面不？”*</span>

### <span style="color:#1E5AA8">**第 54 集 授勋**</span>

- 原部队首长带着仪仗来到槐树老街，当着全街人的面，为陈铁山和林秀英颁授勋章。街坊们这才知道，那个挨了耳光还赔笑的“窝囊老陈”，那个抠门泼辣的老板娘，到底是谁。王婶拉着林秀英的手，哭得说不出话。
  - <span style="color:#888888">*关键台词：首长：“利刃大队铁山、夜莺——国家没有忘记你们。”*</span>

### <span style="color:#1E5AA8">**第 55 集 陈记早点**</span>

- 老街没拆，改造成了文化街，陈记早点重新开张，门口排着长队。陈野毕业后考进了警队，和苏晴并肩巡逻；陈小满继续上学。打烊后，一家四口在天台上吃宵夜，重新定下了家规。
  - <span style="color:#888888">*关键台词：陈铁山：“新家规——咱们不惹事。可事来了，咱家，不怕事。”*</span>
